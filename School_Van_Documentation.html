1. Executive Summary & Project Purpose

The School Van Booking & Live Tracking System is an end-to-end full-stack web platform built to solve two crucial challenges in student transportation: streamlined van admission management and real-time GPS telemetry. Parents and students can register, view available school van services, submit admission forms for dedicated routes, and track the van's live movement on interactive Google Maps while in transit. Concurrently, car owners and drivers receive an authenticated dashboard to oversee admissions and operate a real-time driver tracking console that continuously broadcasts device coordinates via WebSockets.

Student / Parent Portal

  • User Authentication: Secure sign-up/login with hashed passwords and session management.
  • Admission Booking: Apply for transport with student name, class, home address, and school timings.
  • Live Google Maps: Real-time animated marker moving dynamically as the driver travels.
  • Status Feeds: Immediate alerts when trip is started, in progress, or stopped.

Car Owner / Driver Portal

  • Dedicated Owner Login: Secure gatekeeper for administrative actions.
  • Admissions Dashboard: Centralized table to inspect, verify, and delete student requests.
  • Driver Tracking Console: HTML5 Geolocation tracking engine with Start/Stop controls.
  • Telemetry Broadcast: Streams latitude, longitude, speed, and heading over Socket.IO.

2. System Architecture

The system follows a reactive three-tier architecture: the React Single Page Application (SPA), the Node.js Express API with Socket.IO WebSocket server, and the MongoDB database with persistent session store.

3. Core Workflow: Admission & Van Booking

The admission lifecycle begins when a student or parent registers on the platform. Once authenticated via Passport.js, the user submits the student's details, home address, and school information. This data is validated and persisted in the MongoDB admissions collection. The car owner can inspect incoming applications in real time from their administrative dashboard.

4. Core Workflow: Real-Time Live GPS Telemetry

The tracking engine combines the browser HTML5 Geolocation API on the driver's device, an Express REST endpoint for persistence, and a Socket.IO engine for sub-second broadcasting to all connected parents viewing Google Maps.

Figure 3: Sequence Diagram for Real-Time Van GPS Tracking Pipeline
Fault Tolerance: When a parent loads TrackVan.jsx, the client first performs an HTTP GET /api/tracking/current to retrieve the latest known coordinates and trip status, ensuring the map renders correctly even before the next live GPS packet is broadcast.

5. MongoDB Schemas & Data Architecture

The database layer utilizes Mongoose with structured schemas for reliable data persistence:

Collection / Model Key Fields Description & Business Logic
User (userregisters) fullName, parentPhone, email, password (bcrypt hashed) Stores registered students and parents. Auto-logged in upon registration using Passport.js.
CarOwner (carowners) email, password (bcrypt hashed) Administrative accounts for vehicle owners. Seeded automatically on server start with owner@gmail.com.
Admission (admissions) studentName, studentClass, studentAddress, studentContact, schoolName, schoolTime, submittedBy Captures all student transport registration forms. Queried and managed by the car owner dashboard.
VanLocation (vanlocations) latitude, longitude, accuracy, speed, heading, tripStatus, lastUpdated, startedAt, stoppedAt Singleton tracking state for the school van. tripStatus is enum: NOT_STARTED, ACTIVE, or STOPPED.
Session (sessions) _id, session, expires Managed via connect-mongo for persistent user sessions across server restarts.
Contact & LoginLog name, email, message, timestamp Audit log of logins and contact form submissions from prospective students and parents.

6. REST API Endpoints Specification

Method Endpoint Access / Auth Purpose & Response
POST /api/auth/register Public Registers student, hashes password with bcrypt, initializes session.
POST /api/auth/login Public Authenticates student via Passport Local Strategy.
GET /api/auth/logout Student Session Terminates session and clears schoolvan.sid cookie.
POST /api/carowner/login Public Authenticates car owner credentials for admin portal access.
POST /api/admissions Student Session Submits new student van admission application.
GET /api/admissions Car Owner Session Retrieves all student admission requests for management table.
DELETE /api/admissions/:id Car Owner Session Deletes or cancels a specific student admission application.
POST /api/tracking/start Car Owner / Driver Sets tripStatus to ACTIVE; emits trip:started via Socket.IO.
POST /api/tracking/location Car Owner / Driver Saves GPS telemetry; emits van:location:update to all listeners.
POST /api/tracking/stop Car Owner / Driver Sets tripStatus to STOPPED; emits trip:stopped via Socket.IO.
GET /api/tracking/current Public / Protected Returns latest van location and active trip state.
